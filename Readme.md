# Laundry Wallah / Laundry Mart - HTML Webpage

This project is a simple, structured HTML webpage created for **Laundry Wallah / Laundry Mart** as part of the MERN Stack Task 2 assignment. It showcases essential details including services offered, pricing, an online booking form, and contact information.

---

## Features

- **Header Section:** Welcomes visitors to Laundry Wallah / Laundry Mart.
- **About Section:** Provides a concise introduction to the brand and services.
- **Image Section:** Displays a high-quality laundry service image.
- **Services Section:** An itemized list of all available laundry options.
- **Price List Section:** A formatted table displaying pricing for key services.
- **Book Now Section:** A functional form collecting Name, Email, and Phone number (all required).
- **Footer Section:** Contains contact information for customer inquiries.

---

## Files Included

- `index.html`: Main HTML document containing the structure and content of the webpage.
- `Readme.md`: Documentation for the project submission.

---

## How to Run Locally

1. Download or extract the project folder.
2. Double-click the `index.html` file or open it using any modern web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge).
